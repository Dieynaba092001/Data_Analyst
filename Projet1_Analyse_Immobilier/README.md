# Projet 1 : Analyse Immobilière - Dakar

## Objectif
Analyser les prix de l'immobilier à Dakar pour analyser les prix, tendances, zones les plus chères, et construire un dashboard interactif avec KPIs
## Outils utilisés
Excel, Python, Power BI

## Données
Données Expat Dakar 

## Résultats clés
- Le prix moyen au m2 à Almadies est de 85.5M
- Les Top 3 quartiers les moins chers sont : Saly, Nord Foire, Medina
- Les 10 quartiers les plus accéssibles: Cité Keur Gorgui, Lac Rose, Keur Massar, Sacre Coeur, Foire, Sicap, Guédiawaye, Ouakam, Parcelles Assainies et Liberté 6
